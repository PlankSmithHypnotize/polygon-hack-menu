## 🧩 About

**Polygon Companion** is a curated list of Polygon open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD viewer, session switcher
- **Quality-of-Life Helpers** — loadout catalog, settings manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Session Switcher — restart practice from any checkpoint
- Show Hitboxes — visualize object hitboxes
- Replay Notes — record and review match runs
- Playback Speed — adjust practice playback for study (0.1x to 5x)

### Wallhack
- Loadout Catalog — browse weapons, skins, colors, trails
- Custom Skin Notes — organize player cosmetics
- Visibility Tweaks — improved outline visibility

### Aimbot
- Practice Mode Notes — segment study on any layout
- Movement Notes — chain complex maneuvers in the practice range
- Input Buffer Notes — smoother control in the test area
